# skills

A collection of Claude skills. Each skill lives in its own folder under `skills/` and contains a `SKILL.md`.

| Skill | What it does |
|---|---|
| [prototype-brief](skills/prototype-brief/SKILL.md) | Compares a prototype (usually HTML) with a vision or PRD document, flags conflicts and gaps, asks you how to resolve them, then writes a prototype brief for the AI-DLC process. |

## Adding a skill

Create `skills/<skill-name>/SKILL.md` with `name` and `description` in the frontmatter, then add a row to the table above.
